# Metodología de Radar Municipal

## Principios

1. **Separar "no publica" de "gestiona mal"**: la cobertura de datos es una dimensión, no un castigo moral.
2. **Trazabilidad**: cada score tiene fuente, fórmula, fecha, nivel de confianza y advertencias.
3. **Rankings por dimensión**: transparencia, fiscal, normativa, compras, calidad de datos. No un solo número mágico.
4. **Normalización siempre**: per cápita, por km², por km de red vial estimada. Nunca monto bruto.
5. **El rezago se mide en días**: diferencia entre cierre trimestral y fecha de publicación.

## Dimensión: Transparencia

| Criterio | Peso |
|----------|------|
| Presupuesto publicado | 20% |
| Ejecución presupuestaria publicada | 20% |
| Rezago en días desde cierre trimestral | 15% |
| Gasto por finalidad y función | 10% |
| Deuda pública publicada | 10% |
| Accesibilidad (clicks desde home) | 10% |
| Menú de transparencia visible | 5% |
| Machine-readability | 10% |

## Fuentes de datos

- Portales de transparencia municipales
- SIBOM (sibom.slyt.gba.gob.ar)
- ASAP (asap.org.ar)
- INDEC Censo 2022
- Datos Abiertos PBA / ARBA
